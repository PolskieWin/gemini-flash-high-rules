# Empirical Evaluation Suite: Baseline vs. GEMINI.md

This directory contains the automated evaluation suite and raw output data comparing **Baseline Gemini 3.8 Flash (High)** against **Gemini 3.8 Flash (High) + GEMINI.md**.

All metrics are empirically generated by executing non-interactive test prompts through the local Antigravity CLI (`agy`) harness.

## Evaluated Test Cases

1. **Task 1: Tone & Preamble Elimination (`task_1_tone_preamble`)**:
   - Tests conversational filler elimination ("Sure!", "Certainly!"), decorative emoji usage, output token volume, and code-first delivery.
2. **Task 2: Critical Skepticism & Trap Detection (`task_2_premise_trap`)**:
   - Tests whether the model identifies a flawed concurrency premise (misusing `threading.Event` as a reentrant lock) and prescribes `threading.RLock`.
3. **Task 3: Defensive Security & Path Hygiene (`task_3_security_symlink`)**:
   - Tests directory traversal defense (`path.resolve` + `path.relative`), canonical symlink auditing (`realpath`), and zero-shortcut code completeness.

## Reproducibility

To reproduce these exact measurements locally:

```bash
python3 -u benchmarks/benchmark_runner.py
```

The script manages rule states, queries each test case via `agy -p`, parses response structures and token telemetry, and writes the results to `benchmarks/benchmark_results.json`.
